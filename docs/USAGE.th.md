# คู่มือใช้งาน: ตรวจสอบเซิร์ฟเวอร์

## เปิดโปรแกรม

ดับเบิลคลิก `release\ServerBotTracker.exe` โดยเก็บไฟล์ `ServerBotTracker.exe.config` ไว้ในโฟลเดอร์เดียวกัน ใช้กับ Windows ที่มี .NET Framework 4.8 ขึ้นไป ไม่ต้องเปิด PowerShell หรือใช้สิทธิ์ผู้ดูแลระบบ

## เพิ่มรายการ

1. กด **เพิ่มเซิร์ฟเวอร์**
2. ใส่ชื่อที่ใช้จำรายการ เช่น “เครื่องรายงาน”
3. ใส่ IP หรือชื่อโฮสต์ เช่น `10.0.0.97` หรือ `report-server` โดยไม่ใส่ `http://`, `https://` หรือพอร์ตต่อท้าย
4. เลือก **ICMP + TCP**, **ICMP เท่านั้น** หรือ **TCP เท่านั้น**
5. กำหนดพอร์ตบริการที่ต้องการตรวจ แล้วกด **บันทึก**

พอร์ตต้องตรงกับบริการของเครื่องนั้น เช่น เว็บ HTTPS อาจใช้ 443 แต่เครื่องที่ไม่มีบริการบน 443 จะตรวจ TCP ไม่ผ่านแม้ตัวเครื่องยังเชื่อมต่อได้ หากต้องการตรวจหลายพอร์ตของเครื่องเดียวกัน ให้เพิ่มหลายรายการโดยเปลี่ยนชื่อและพอร์ต

กด **วางหลายรายการ** เพื่อวาง IP หรือชื่อโฮสต์บรรทัดละหนึ่งรายการ ทุกบรรทัดใช้ ICMP + TCP และพอร์ตเดียวกันตามที่เลือก รายการซ้ำในข้อความหรือรายการเดิมที่โฮสต์ พอร์ต และวิธีตรวจเหมือนกันจะถูกข้าม จากนั้นแก้ไขแต่ละรายการได้

## ตรวจสอบ

- **ตรวจทั้งหมด**: ตรวจรายการที่บันทึกทั้งหมด แม้บางรายการถูกซ่อนด้วยช่องค้นหา
- **ตรวจที่เลือก**: ตรวจเฉพาะแถวที่เลือก ใช้ Ctrl หรือ Shift เพื่อเลือกหลายแถว
- **รอสูงสุด (ms)**: เวลารอแต่ละขั้นตอน DNS และแต่ละการตรวจ ICMP/TCP มีเวลารอของตัวเอง
- **ตรวจอัตโนมัติ**: ตรวจทันที แล้วเว้นระยะตามจำนวนวินาทีหลังรอบก่อนตรวจเสร็จ ไม่มีรอบที่ทำงานซ้อนกัน
- **หยุด**: ยกเลิกรอบที่กำลังตรวจและปิดการตรวจอัตโนมัติ รายการที่ยังไม่เสร็จคงผลก่อนหน้า ให้ดูเวลาตรวจล่าสุดประกอบ

โปรแกรมตรวจพร้อมกันสูงสุดแปดรายการ หน้าต่างยังใช้งานได้ระหว่างรอเครือข่าย ปุ่มแก้ไขรายการและการตั้งค่าจะถูกปิดชั่วคราวจนจบรอบ ตรวจอัตโนมัติจะปิดเมื่อเปิดโปรแกรมใหม่

## แปลผล

| สถานะ | ความหมาย |
| --- | --- |
| ผ่าน | ทุกวิธีที่เลือกตรวจสำเร็จ |
| ผ่านบางส่วน | เลือกทั้ง ICMP/TCP แต่ผ่านเพียงวิธีเดียว |
| ไม่ผ่าน | ทุกวิธีที่เลือกตรวจไม่สำเร็จ |
| ยังไม่ตรวจ | ยังไม่มีผลการตรวจเสร็จในครั้งที่เปิดโปรแกรมนี้ |

**ICMP ไม่ผ่านไม่ใช่หลักฐานว่าเครื่องดับ** อาจถูกไฟร์วอลล์บล็อกได้ **TCP ผ่านหมายถึงเชื่อมต่อพอร์ตได้** ยังไม่ได้ตรวจว่าเว็บไซต์ ฐานข้อมูล หรือบริการข้างในทำงานถูกต้อง

เลือกแถวหรือชี้เมาส์ที่เซลล์เพื่อดู IP ที่ตรวจจริงและข้อความผลลัพธ์ โปรแกรมเลือก IPv4 แรกจาก DNS หากไม่มีจึงใช้ IP แรกที่ได้ ไม่ได้ตรวจ IP ทุกตัวของชื่อโฮสต์ที่กระจายโหลด วันที่แสดงเป็น ค.ศ. และเวลาตาม Windows ของเครื่องที่ใช้งาน

## แก้ไข ลบ และส่งออก

เลือกหนึ่งแถวแล้วกด **แก้ไข** หรือดับเบิลคลิกแถวนั้น เมื่อแก้ไขแล้วผลเดิมของรายการนั้นจะถูกล้างเพื่อไม่ให้ปะปนกับโฮสต์/พอร์ตใหม่

เลือกแถวแล้วกด **ลบ** โปรแกรมขอยืนยันก่อนลบ การลบเป็นการลบรายการในโปรแกรม ไม่ได้ลบหรือแก้ไขข้อมูลบนเซิร์ฟเวอร์

กด **ส่งออก CSV** เพื่อบันทึกผลล่าสุดของรายการทั้งหมด ไฟล์ใช้ UTF-8 พร้อม BOM สำหรับข้อความภาษาไทยใน Excel ผลเป็นภาพรวม ณ ขณะส่งออก ไม่มีประวัติย้อนหลัง ชื่อที่อาจถูก Excel อ่านเป็นสูตรจะถูกป้องกันด้วยเครื่องหมาย `'`

## ที่เก็บข้อมูลและการย้ายเครื่อง

รายการและค่าการตั้งค่าอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker\servers.json` ของผู้ใช้ Windows แต่ละคน ไม่อยู่ในโฟลเดอร์โค้ดหรือข้าง EXE ไฟล์ `.bak` เป็นข้อมูลก่อนบันทึกครั้งล่าสุด

ย้ายตัวโปรแกรมโดยคัดลอกโฟลเดอร์ `release` หากต้องการย้ายรายการด้วย ให้ปิดโปรแกรมทั้งสองเครื่องแล้วคัดลอก `servers.json` ไปยังตำแหน่งเดียวกันของผู้ใช้ในเครื่องปลายทาง ก่อนแทนที่ข้อมูลปลายทางให้สำรองไว้ก่อน

หากข้อมูลเสีย โปรแกรมจะแจ้งข้อผิดพลาดโดยไม่เขียนทับไฟล์เดิม ปิดโปรแกรม สำรองไฟล์เดิม แล้วตรวจสอบหรือกู้จาก `.bak` ผลการตรวจเชื่อมต่อไม่ได้ถูกบันทึกถาวร จึงเริ่มจาก “ยังไม่ตรวจ” ทุกครั้งที่เปิดใหม่
