# คู่มือ: Dashboard ตรวจสอบเซิร์ฟเวอร์ด้วย Ping

## เริ่มใช้งาน

ดับเบิลคลิก `release\ServerBotTracker.exe` และเก็บ `ServerBotTracker.exe.config` ไว้ข้างกัน ใช้กับ Windows ที่มี .NET Framework 4.8 ขึ้นไป

1. กด **เพิ่มเซิร์ฟเวอร์**
2. ใส่ชื่อ เช่น “เครื่องรายงาน”
3. ใส่ IP หรือชื่อโฮสต์ เช่น `10.0.0.97` หรือ `report-server`
4. กด **บันทึก** แล้วกด **ตรวจทั้งหมด**

ระบุเฉพาะ IP/ชื่อโฮสต์ ไม่ใส่ URL หรือพอร์ต โปรแกรมตรวจด้วย Ping ทุกครั้ง ช่องเพิ่มรายการมีเพียงชื่อและ IP/โฮสต์

**วางหลายรายการ** ใช้เพิ่ม IP/ชื่อโฮสต์บรรทัดละหนึ่งรายการ รายการซ้ำในข้อความหรือโฮสต์ที่มีอยู่แล้วจะถูกข้าม เลือกแถวแล้วกด **แก้ไข** เพื่อเปลี่ยนชื่อ หรือ **ลบ** เพื่อลบรายการหลังยืนยัน

## อ่าน Dashboard

| สิ่งที่แสดง | ความหมาย |
| --- | --- |
| ผ่าน สีเขียว | ได้รับคำตอบ Ping |
| ไม่ผ่าน สีแดง | ไม่ได้รับคำตอบสำเร็จ เช่น หมดเวลาหรือค้นหาชื่อโฮสต์ไม่ได้ |
| ยังไม่ตรวจ | ยังไม่มีผลการตรวจเสร็จในครั้งที่เปิดโปรแกรมนี้ |
| เวลาตอบกลับ (ms) | เวลาที่ใช้รับคำตอบ Ping หน่วยมิลลิวินาที |
| ตรวจล่าสุด | วันเวลาที่ตรวจรายการนั้นเสร็จ |

เลือกแถวหรือชี้เมาส์ที่เซลล์เพื่อดูข้อความผลลัพธ์และ IP ที่ตรวจจริง ผล “ไม่ผ่าน” อาจเกิดจากไฟร์วอลล์ที่บล็อก Ping ได้ วันที่แสดงเป็น ค.ศ. และเวลาตาม Windows ของเครื่องที่ใช้งาน

## ตรวจด้วยตนเองหรือเป็นรอบ

- **ตรวจทั้งหมด** ตรวจทุกรายการ แม้บางรายการถูกซ่อนด้วยช่องค้นหา
- **ตรวจที่เลือก** ตรวจเฉพาะแถวที่เลือก ใช้ Ctrl/Shift เพื่อเลือกหลายแถว
- **ตรวจอัตโนมัติ** ตรวจทันที จากนั้นเว้นระยะตามจำนวนวินาทีหลังรอบก่อนจบ
- **หยุด** ยกเลิกรอบปัจจุบันและปิดการตรวจอัตโนมัติ รายการที่ยังไม่เสร็จคงผลก่อนหน้า ให้ดูเวลาตรวจล่าสุดประกอบ
- **รอสูงสุด (ms)** กำหนดเวลารอต่อขั้นตอน DNS และต่อคำขอ Ping
- **รอบตรวจ (วินาที)** กำหนดช่วงเว้นระหว่างรอบอัตโนมัติ

ส่ง Ping หนึ่งครั้งต่อเซิร์ฟเวอร์ต่อรอบ และตรวจพร้อมกันสูงสุดแปดรายการ ไม่มีรอบตรวจซ้อนกัน ตรวจอัตโนมัติปิดเมื่อเปิดโปรแกรมใหม่ ช่องค้นหาใช้ค้นชื่อหรือโฮสต์

## ข้อมูลที่บันทึก

รายการและการตั้งค่าอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker\servers.json` ของผู้ใช้ Windows ไฟล์ `.bak` เป็นข้อมูลก่อนบันทึกครั้งล่าสุด ผลตรวจไม่ได้เก็บข้ามการเปิดโปรแกรม

รายการจากรุ่นก่อนยังเปิดได้ ชื่อ IP/โฮสต์ และรหัสรายการยังคงเดิม ข้อมูลพอร์ตและวิธีตรวจเดิมเลิกใช้ เมื่อบันทึกตามปกติจะเปลี่ยนเป็นรูปแบบใหม่พร้อมสำรองไฟล์เดิม ไม่มีการรวมรายการเดิมที่ใช้โฮสต์เดียวกันโดยอัตโนมัติ

ย้ายตัวโปรแกรมโดยคัดลอกโฟลเดอร์ `release` หากต้องการย้ายรายการ ให้ปิดโปรแกรมและคัดลอก `servers.json` ไปยังตำแหน่งเดียวกันของผู้ใช้ปลายทาง โดยสำรองไฟล์ปลายทางก่อนแทนที่

หากข้อมูลเสีย โปรแกรมจะแจ้งข้อผิดพลาดและไม่เขียนทับไฟล์เดิม ปิดโปรแกรมและสำรองข้อมูลก่อนตรวจสอบหรือกู้จาก `.bak`

## อัปเดตและการแจ้งเตือน (รุ่น 1.2)

แนะนำให้ใช้ `ServerBotTracker-Setup.exe` สำหรับติดตั้งตามปกติ โปรแกรมจะอยู่ใน Start menu ชื่อ **Server Bot Tracker** และถอนการติดตั้งผ่าน Windows ได้ ข้อมูลเซิร์ฟเวอร์เก็บแยกจากตัวโปรแกรม

ปุ่ม **อัปเดต / เกี่ยวกับ** แสดงรุ่นปัจจุบัน สถานะช่องทางเผยแพร่ และตัวเลือกอัปเดตอัตโนมัติ โปรแกรมตรวจเมื่อเปิดและทุกสิบนาที หากมีรุ่นใหม่จะดาวน์โหลดและตรวจสอบไฟล์ แล้วติดตั้งหลังปิดโปรแกรม ปุ่ม **อัปเดตและเริ่มใหม่** ใช้เริ่มใหม่ทันทีหลังติดตั้ง หากก่อนหน้านั้นตรวจ Ping อัตโนมัติอยู่ จะกลับมาตรวจต่อหลังการเริ่มใหม่จากอัปเดต

ปุ่ม **การแจ้งเตือน** แสดงประกาศจากผู้พัฒนาและสถานะเซิร์ฟเวอร์ที่เปลี่ยนไป เมื่อ Ping ไม่ผ่านสองรอบติดต่อกันจะแจ้งหนึ่งครั้ง และแจ้งอีกครั้งเมื่อได้รับคำตอบแล้ว การไม่ผ่านต่อเนื่องจะไม่เตือนซ้ำในช่วงที่เปิดโปรแกรมเดียวกัน ปิดหรือเปิดการแจ้งเตือนเซิร์ฟเวอร์ได้ในหน้านี้

ข้อความเก็บใน `notifications.json` ข้าง `servers.json` สูงสุด 100 รายการ กด **อ่านทั้งหมดแล้ว** เพื่อล้างจำนวนที่ยังไม่อ่าน ประกาศใช้ ID เพื่อไม่แจ้งซ้ำเมื่อเปิดโปรแกรมใหม่ Windows อาจไม่แสดง popup ตามการตั้งค่าของ Windows แต่ข้อความยังอยู่ในกล่องแจ้งเตือน

เมื่อช่องทาง GitHub ยังไม่พร้อมหรืออินเทอร์เน็ตใช้ไม่ได้ โปรแกรมจะแสดงสถานะติดต่ออัปเดตไม่ได้ โดยยังตรวจ Ping ได้ตามปกติ รายการเซิร์ฟเวอร์และข้อความเตือนภายในไม่ได้ส่งไปยัง GitHub รุ่นก่อน 1.2 ต้องติดตั้งรุ่นนี้ครั้งแรกก่อนจึงจะอัปเดตอัตโนมัติในอนาคตได้

การออกเวอร์ชันและประกาศสำหรับเจ้าของโปรแกรมดู [คู่มือเผยแพร่](RELEASES.th.md)
