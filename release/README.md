# FKP Server Monitor 1.7.0

เปิด **FKPServerMonitor-Setup.exe** เพื่อติดตั้ง เริ่มต้นที่ `C:\Program Files\FKP Server Monitor` หรือเลือกไดรฟ์และโฟลเดอร์อื่นได้ ตัวติดตั้งสร้างโฟลเดอร์ให้ ติดตั้งสำหรับทุกคนในเครื่อง และขอสิทธิ์ผู้ดูแลระบบเมื่อเริ่มติดตั้ง

ขั้นตอน: **ถัดไป > เลือกโฟลเดอร์ติดตั้ง > ยืนยันตำแหน่ง > ติดตั้ง > เสร็จสิ้น** กด **เรียกดู...** เพื่อเลือกไดรฟ์หรือโฟลเดอร์หลัก ระบบเพิ่มชื่อโฟลเดอร์ FKP Server Monitor ให้ครั้งเดียว เช่น `D:\FKP Server Monitor` หรือพิมพ์พาธเต็มเอง

เปิดจาก Start menu ชื่อ **FKP Server Monitor** โปรแกรมใช้สิทธิ์ผู้ใช้ปกติ ต้องมี Windows และ .NET Framework 4.8 ขึ้นไป สีหน้าจอและไอคอนหุ่นยนต์เดิมยังคงอยู่

ผู้ใช้ Server Bot Tracker ให้รันตัวติดตั้งใหม่นี้หนึ่งครั้ง หากมีการติดตั้งเดิม ตัวติดตั้งจะจำโฟลเดอร์ที่ลงไว้ เลือกโฟลเดอร์เดิมเพื่อเปลี่ยน EXE ทางลัด และชื่อใน Control Panel โดยไม่ลบข้อมูลผู้ใช้ หากติดตั้งใหม่ให้ใช้โฟลเดอร์เริ่มต้นชื่อใหม่

ถอนการติดตั้งได้จาก **Control Panel > Programs and Features > FKP Server Monitor > Uninstall/Change** หรือดับเบิลคลิก **Uninstall.exe** ภายในโฟลเดอร์ติดตั้ง หากโปรแกรมยังเปิดอยู่ ให้ปิดก่อนแล้วลองอีกครั้ง ระบบตรวจไฟล์ก่อนเปลี่ยนและคืนค่าเมื่อขั้นตอนถอนล้มเหลว

แบบ Portable: เปิด **FKPServerMonitor.exe** และเก็บ **FKPServerMonitor.exe.config** ไว้ข้างกัน

เพิ่มชื่อกับ IP/โฮสต์ แล้วกด **ตรวจทั้งหมด** เพื่อดูผล Ping ผ่านหรือไม่ผ่าน ไม่มีช่องพอร์ตและไม่มีรายงาน CSV

- **อัปเดต / เกี่ยวกับ** ตรวจรุ่นใหม่ ดาวน์โหลด และติดตั้งเมื่อปิดโปรแกรม
- **การแจ้งเตือน** อ่านประกาศผู้พัฒนา รวมถึงแจ้งเมื่อ Ping ไม่ผ่านต่อเนื่องหรือกลับมาเชื่อมต่อได้
- รายการเซิร์ฟเวอร์และประวัติแจ้งเตือนยังอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker` เพื่อให้รายการเดิมใช้งานต่อได้
- ช่องทางเผยแพร่ยังเป็น `github.com/kumatech112/Server_Bot_Tracker` เพื่อรักษาลิงก์เดิม

`publish/v1.7.0` มีตัวติดตั้ง ZIP และ manifest สำหรับเผยแพร่ โปรแกรมชื่อใหม่ใช้ `update-fkp.json` ส่วน `update.json` ยังคงชี้รุ่น 1.6 ที่โปรแกรมชื่อเดิมยอมรับ ผู้ใช้ชื่อเดิมต้องรัน Setup ใหม่ครั้งเดียวเพื่อเปลี่ยนช่องทางอัปเดต

การสร้างไฟล์ในโฟลเดอร์นี้ยังไม่ได้เผยแพร่อัปเดตสาธารณะ ตัวติดตั้งยังไม่มีลายเซ็นใบรับรองผู้เผยแพร่ Windows
