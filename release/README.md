# Server Bot Tracker 1.6.0

เปิด `ServerBotTracker-Setup.exe` เพื่อติดตั้งสำหรับทุกคนในเครื่อง เริ่มต้นที่ `C:\Program Files\ServerBotTracker` หรือเลือกไดรฟ์อื่นได้ ตัวติดตั้งสร้างโฟลเดอร์ให้และขอสิทธิ์ผู้ดูแลระบบเมื่อเริ่มติดตั้ง จากนั้นเปิดจาก Start menu ชื่อ **Server Bot Tracker** ตัว Dashboard ใช้สิทธิ์ผู้ใช้ปกติและต้องมี .NET Framework 4.8 ขึ้นไป

ตัวติดตั้งเป็นแบบ Wizard: **ถัดไป > เลือกโฟลเดอร์ติดตั้ง > ยืนยันตำแหน่ง > ติดตั้ง > เสร็จสิ้น** กด **เรียกดู...** เลือกไดรฟ์หรือโฟลเดอร์หลัก ระบบสร้างโฟลเดอร์ `ServerBotTracker` ให้ เช่น `D:\ServerBotTracker` หรือพิมพ์พาธเต็มเอง ตรวจตำแหน่งสุดท้ายก่อนกดติดตั้ง โปรแกรมจำตำแหน่งไว้ครั้งถัดไป พร้อมปุ่มย้อนกลับและยกเลิก ใช้แผงภาพสีน้ำเงิน ไอคอนหุ่นยนต์ และหน้าข้อความสีขาว ส่วนหน้าจอ Dashboard คงสีเดิมไว้

ถอนการติดตั้งได้จาก **Control Panel > Programs and Features > Server Bot Tracker > Uninstall/Change** แล้วทำตามตัวช่วยถอนการติดตั้ง รายการเซิร์ฟเวอร์และการตั้งค่าส่วนตัวยังคงอยู่ ต้องรัน Setup รุ่นนี้หนึ่งครั้งเพื่อเปลี่ยนตัวถอนการติดตั้งเดิม

รุ่น 1.5.2 แก้ไขการเปิด **Uninstall.exe** โดยตรง ให้เข้าโหมดถอนการติดตั้งทันที ไม่เข้าโหมดติดตั้งผิดเหมือนรุ่นก่อน สามารถดับเบิลคลิกไฟล์นี้จากโฟลเดอร์โปรแกรมได้หลังติดตั้ง Setup รุ่นนี้

รุ่น 1.6 ตรวจไฟล์ก่อนถอน หากไฟล์ถูกใช้งานจะหยุดก่อนนำออก หากขั้นตอนถัดไปล้มเหลวจะคืนไฟล์เดิมให้ หากถอนได้แล้วแต่ยังลบไฟล์ชั่วคราวไม่ได้ จะแจ้งสถานะว่าถอนเสร็จพร้อมรายละเอียดไฟล์ชั่วคราว การติดตั้ง ถอน และอัปเดตในตำแหน่งป้องกันจะขอสิทธิ์ผู้ดูแลระบบจาก Windows

หากต้องการแบบ Portable ให้เปิด `ServerBotTracker.exe` โดยเก็บ `ServerBotTracker.exe.config` ไว้ข้างกัน

กด **เพิ่มเซิร์ฟเวอร์** ใส่ชื่อและ IP/โฮสต์ แล้วกด **ตรวจทั้งหมด** โปรแกรมตรวจด้วย Ping แสดง **ผ่าน** สีเขียวหรือ **ไม่ผ่าน** สีแดง พร้อมเวลาตรวจล่าสุด ไม่มีช่องพอร์ตและไม่มีรายงาน CSV

- **อัปเดต / เกี่ยวกับ** ตรวจรุ่นใหม่ ดาวน์โหลดอัตโนมัติ และติดตั้งเมื่อปิดโปรแกรม หรือกดอัปเดตและเริ่มใหม่
- **การแจ้งเตือน** อ่านประกาศจากผู้พัฒนา และแจ้งเมื่อ Ping ไม่ผ่านสองรอบติดต่อกันหรือกลับมาเชื่อมต่อได้
- ช่องทางสาธารณะที่กำหนดไว้: `github.com/kumatech112/Server_Bot_Tracker` ต้องมี repository และ release เผยแพร่แล้วจึงจะดาวน์โหลดได้

รายการและการแจ้งเตือนอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker` รุ่นก่อนยังโหลดรายการได้ การอัปเดตหรือถอนการติดตั้งไม่ลบไฟล์รายการผู้ใช้

โฟลเดอร์ `publish/v1.6.0` มีตัวติดตั้ง ZIP และ update.json ที่เตรียมไว้เผยแพร่ ไม่มีโค้ดหรือข้อมูลเซิร์ฟเวอร์แนบอยู่ ตัวติดตั้งรุ่นนี้ยังไม่ได้เซ็นใบรับรองผู้เผยแพร่ Windows
