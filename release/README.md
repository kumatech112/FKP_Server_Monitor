# Server Bot Tracker 1.5.1

เปิด `ServerBotTracker-Setup.exe` เพื่อติดตั้งสำหรับผู้ใช้ Windows คนปัจจุบัน จากนั้นเปิดจาก Start menu ชื่อ **Server Bot Tracker** ใช้ .NET Framework 4.8 ขึ้นไป เลือกโฟลเดอร์ที่บัญชี Windows ของคุณเขียนไฟล์ได้ ตัวติดตั้งไม่ยกระดับสิทธิ์อัตโนมัติ

ตัวติดตั้งเป็นแบบ Wizard: **ถัดไป > เลือกโฟลเดอร์ติดตั้ง > ยืนยันตำแหน่ง > ติดตั้ง > เสร็จสิ้น** พิมพ์พาธหรือกด **เรียกดู...** เพื่อเลือกตำแหน่ง โปรแกรมจะใช้โฟลเดอร์ที่เลือกโดยตรงและจำไว้ครั้งถัดไป พร้อมปุ่มย้อนกลับและยกเลิก ใช้แผงภาพสีน้ำเงิน ไอคอนหุ่นยนต์ และหน้าข้อความสีขาว ส่วนหน้าจอ Dashboard คงสีเดิมไว้

ถอนการติดตั้งได้จาก **Control Panel > Programs and Features > Server Bot Tracker > Uninstall/Change** แล้วทำตามตัวช่วยถอนการติดตั้ง รายการเซิร์ฟเวอร์และการตั้งค่าส่วนตัวยังคงอยู่ ต้องรัน Setup รุ่นนี้หนึ่งครั้งเพื่อเปลี่ยนตัวถอนการติดตั้งเดิม

หากต้องการแบบ Portable ให้เปิด `ServerBotTracker.exe` โดยเก็บ `ServerBotTracker.exe.config` ไว้ข้างกัน

กด **เพิ่มเซิร์ฟเวอร์** ใส่ชื่อและ IP/โฮสต์ แล้วกด **ตรวจทั้งหมด** โปรแกรมตรวจด้วย Ping แสดง **ผ่าน** สีเขียวหรือ **ไม่ผ่าน** สีแดง พร้อมเวลาตรวจล่าสุด ไม่มีช่องพอร์ตและไม่มีรายงาน CSV

- **อัปเดต / เกี่ยวกับ** ตรวจรุ่นใหม่ ดาวน์โหลดอัตโนมัติ และติดตั้งเมื่อปิดโปรแกรม หรือกดอัปเดตและเริ่มใหม่
- **การแจ้งเตือน** อ่านประกาศจากผู้พัฒนา และแจ้งเมื่อ Ping ไม่ผ่านสองรอบติดต่อกันหรือกลับมาเชื่อมต่อได้
- ช่องทางสาธารณะที่กำหนดไว้: `github.com/kumatech112/Server_Bot_Tracker` ต้องมี repository และ release เผยแพร่แล้วจึงจะดาวน์โหลดได้

รายการและการแจ้งเตือนอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker` รุ่นก่อนยังโหลดรายการได้ การอัปเดตหรือถอนการติดตั้งไม่ลบไฟล์รายการผู้ใช้

โฟลเดอร์ `publish/v1.5.1` มีตัวติดตั้ง ZIP และ update.json ที่เตรียมไว้เผยแพร่ ไม่มีโค้ดหรือข้อมูลเซิร์ฟเวอร์แนบอยู่ ตัวติดตั้งรุ่นนี้ยังไม่ได้เซ็นใบรับรองผู้เผยแพร่ Windows
