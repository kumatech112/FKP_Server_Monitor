# โปรแกรมพร้อมใช้งาน

ดับเบิลคลิก `ServerBotTracker.exe` โดยเก็บ `ServerBotTracker.exe.config` ไว้ข้างกัน

ต้องใช้ Windows ที่มี .NET Framework 4.8 ขึ้นไป ไม่ต้องใช้ Python เปิดเทอร์มินัล หรือใช้สิทธิ์ผู้ดูแลระบบ

กด **เพิ่มเซิร์ฟเวอร์** เพื่อระบุชื่อ IP/โฮสต์ วิธีตรวจ ICMP/TCP และพอร์ตบริการ แล้วกด **ตรวจทั้งหมด** หรือ **ตรวจที่เลือก** ใช้ **วางหลายรายการ** เพื่อเพิ่ม IP/โฮสต์บรรทัดละหนึ่งรายการ และเปิด **ตรวจอัตโนมัติ** เมื่อต้องการตรวจเป็นรอบ

รายการและการตั้งค่าอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker\servers.json` ของผู้ใช้ Windows ไม่อยู่ข้าง EXE คัดลอกโฟลเดอร์นี้เพื่อย้ายตัวโปรแกรม และย้ายไฟล์ตั้งค่าต่างหากหากต้องการรายการเดิม โดยปิดโปรแกรมก่อนคัดลอก ผลตรวจล่าสุดไม่ได้ถูกเก็บข้ามการเปิดโปรแกรม

ICMP ไม่ผ่านอาจถูกไฟร์วอลล์บล็อก ส่วน TCP ผ่านยืนยันเพียงเชื่อมต่อพอร์ตได้ ยังไม่ยืนยันว่าบริการทำงานสมบูรณ์

โฟลเดอร์นี้มีเฉพาะตัวโปรแกรมและคู่มือ ไฟล์ EXE/การตั้งค่ารันไทม์ที่สร้างขึ้นไม่ถูกเก็บใน Git สร้างใหม่ได้ด้วย `tools/Build.ps1` ในโปรเจคต้นฉบับ
