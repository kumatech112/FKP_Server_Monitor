# โปรแกรมพร้อมใช้งาน: Dashboard ตรวจสอบเซิร์ฟเวอร์

ดับเบิลคลิก `ServerBotTracker.exe` โดยเก็บ `ServerBotTracker.exe.config` ไว้ข้างกัน ต้องใช้ Windows ที่มี .NET Framework 4.8 ขึ้นไป

กด **เพิ่มเซิร์ฟเวอร์** ใส่ชื่อและ IP/โฮสต์ แล้วกด **ตรวจทั้งหมด** โปรแกรมตรวจด้วย Ping และแสดง **ผ่าน** สีเขียว หรือ **ไม่ผ่าน** สีแดง พร้อมเวลาตรวจล่าสุด

ใช้ **วางหลายรายการ** เพื่อเพิ่ม IP/โฮสต์บรรทัดละหนึ่งรายการ เปิด **ตรวจอัตโนมัติ** เมื่อต้องการตรวจเป็นรอบ และกด **หยุด** เพื่อยกเลิกการตรวจ

ไม่ต้องระบุพอร์ต และไม่มีการส่งออกรายงาน หากไม่ได้รับคำตอบ Ping อาจเกิดจากเครื่องไม่ตอบหรือไฟร์วอลล์บล็อก ให้ดูข้อความรายละเอียดและเวลาตรวจล่าสุดประกอบ

รายการอยู่ที่ `%LOCALAPPDATA%\Kuma\ServerBotTracker\servers.json` ไม่อยู่ข้าง EXE รายการจากรุ่นก่อนยังเปิดได้ ผลตรวจเริ่มใหม่ทุกครั้งที่เปิดโปรแกรม

คัดลอกโฟลเดอร์นี้เพื่อย้ายตัวโปรแกรม หากต้องการรายการเดิมให้ย้ายไฟล์ตั้งค่าต่างหาก โดยปิดโปรแกรมก่อนคัดลอก ไฟล์โปรแกรมที่สร้างขึ้นไม่ถูกเก็บใน Git; สร้างใหม่ได้ด้วย `tools/Build.ps1` ในโปรเจคต้นฉบับ
